# ☕ Java Básico — Controle de Fluxo, Arrays e Métodos (Parte 2)

Repositório com as resoluções dos **10 primeiros exercícios** da apostila *Java Básico - Parte 2*, desenvolvidos no **IntelliJ IDEA**. O foco desta etapa é o controle de iterações em laços, manipulação de arrays unidimensionais e modularização inicial com métodos.

## 📋 Exercícios Resolvidos

| Classe | Tema | Descrição |
| :--- | :--- | :--- |
| `Exercicio01` | Comando `break` | Interrupção de um laço `for` de 1 a 10 ao atingir o valor 6. |
| `Exercicio02` | Comando `continue` | Salto de iteração específica (ignorando o número 5) em contagem de 1 a 10. |
| `Exercicio03` | Filtro com `continue` | Exibição de números de 1 a 20 omitindo todos os múltiplos de 4. |
| `Exercicio04` | Arrays (acesso inicial) | Criação de array de inteiros com 5 posições e exibição do primeiro índice (`[0]`). |
| `Exercicio05` | Arrays (`length - 1`) | Acesso dinâmico ao último elemento de um array de `String`. |
| `Exercicio06` | Alteração de array | Modificação de posição específica do array e leitura via laço `for-each`. |
| `Exercicio07` | Propriedade `length` | Contagem e exibição do tamanho total de um array de cidades. |
| `Exercicio08` | `for` tradicional | Percorrimento de array de notas exibindo o índice e o valor correspondente. |
| `Exercicio09` | Laço `for-each` | Leitura sequencial de um array de produtos sem manipulação de índices. |
| `Exercicio10` | Métodos (`void`) | Criação e chamadas múltiplas do método `exibirMensagem()` a partir do `main`. |
